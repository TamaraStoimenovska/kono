
A modern, fully responsive landing page built with Next.js 13, React 18, TypeScript, and Tailwind CSS.

✨ Features

⚡ Next.js 13 + React 18 for fast rendering and SEO-friendly architecture

🎨 Tailwind CSS for clean, scalable, and responsive design

🧱 Reusable and modular React components

📱 Fully responsive across mobile, tablet, and desktop

🧭 Sections for hero, about, features, testimonials, pricing, FAQ, and contact

⚙️ Built with TypeScript for better reliability and maintainability

🧩 Tech Stack

Framework: Next.js 13

Language: TypeScript

UI Library: React 18

Styling: Tailwind CSS


## Installation
    
```bash
    yarn install
 ```
You can start the project on the local server
    
```bash
    yarn dev
 ```

It’ll start on [localhost:3000](http://localhost:3000).
